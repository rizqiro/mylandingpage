# About carousel photos

Drop your photos here using these exact filenames so they show up
automatically in the About section's carousel (see `index.html`,
`#aboutCarousel`):

- `slide-1.jpg`
- `slide-2.jpg`
- `slide-3.jpg`

Any image format works as long as the filename (including extension)
matches what's referenced in `index.html` — or edit the `<img src="...">`
path there to match your own filename instead.

Until a file exists at one of these paths, that slide shows a dashed
placeholder (camera icon + the expected path) instead of a broken image.
